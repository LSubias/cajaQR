# Caja QR

Sistema de caja e inventario para ventas pagadas por transferencia.

El vendedor carga los productos y genera un QR. El comprador lo escanea para ver los ítems y el total de la venta y adjuntar el comprobante desde el celular. El vendedor recibe la captura en la pantalla de caja y puede registrar la entrega y verificar el pago en momentos distintos.

El proyecto usará la instancia de Supabase de Luna Rosa, con tablas y almacenamiento propios.

Este repositorio contiene la estructura inicial. La aplicación todavía no está implementada.
